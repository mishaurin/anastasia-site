# Anastasia Mishurina — Сайт визажиста

Официальный сайт профессионального визажиста Анастасии Мишуриной.

## Структура файлов

```
anastasia-site/
├── index.html          ← Главная страница сайта
├── photos.json         ← Список фотографий портфолио
├── hero.json           ← Список фотографий карусели на главной
├── check-photos.js     ← Проверка фото перед коммитом (node check-photos.js)
├── netlify.toml        ← Настройки хостинга
├── README.md           ← Этот файл
└── photos/
    ├── hero/           ← Фото для главной карусели (hero.json)
    ├── mariage/        ← Свадебные фото
    ├── gala/           ← Гала и вечерние мероприятия
    ├── tv/             ← Телевидение и интервью
    └── shooting/       ← Фотосъёмки
```

## Как добавить новое фото в портфолио

1. Загрузите файл в нужную папку (`photos/mariage/`, `photos/gala/` и т.д.)
2. Откройте файл `photos.json` и добавьте новую строку:

```json
{
  "file": "имя-файла.jpg",
  "category": "mariage",
  "caption_fr": "Подпись на французском",
  "caption_en": "Caption in English"
}
```

3. Запустите `node check-photos.js` — убедитесь, что нет ошибок.
4. Закоммитьте и запушьте (GitHub Desktop) — сайт обновится за 30–60 секунд.

## Как удалить фото из портфолио

1. Откройте `photos.json`
2. Удалите строку с нужным фото
3. Закоммитьте и запушьте

Сам файл из папки `photos/` можно тоже удалить — но это необязательно, на отображение сайта не влияет.

## Как обновить фото в карусели на главной

Карусель — это 5 фиксированных слайдов (Mariage, Gala & Soirée, Fashion Week, Plateau TV & Interview, Shooting Editorial), их текст и порядок заданы в `hero.json`. У каждого слайда есть поле `"file"`:

```json
{
  "file": "IMG_1234.JPG",
  "category": "Gala & Soirée",
  "title": "L'élégance",
  "titleEm": "à son apogée",
  "location": "Cannes · Paris · Monaco",
  "btnLabel": "Découvrir",
  "btnHref": "#contact"
}
```

1. Загрузите фото в `photos/hero/`.
2. В `hero.json` найдите нужный слайд и впишите имя файла в `"file"` (точно как на диске, с учётом регистра).
3. Если для слайда пока нет фото — оставьте `"file": null`, тогда покажется заглушка-иконка вместо фото.
4. Запустите `node check-photos.js`, затем закоммитьте и запушьте.

Менять текст (`title`, `titleEm`, `location`, `btnLabel`, `btnHref`) можно точно так же, прямо в JSON.

## Рекомендации по фотографиям

- **Формат:** JPG
- **Минимальный размер:** 1200px по ширине
- **Вес файла:** до 500 Кб (сжимайте через [Squoosh](https://squoosh.app) — бесплатно)
- **Имена файлов:** только латиница, без пробелов и спецсимволов (используйте дефис `-`)

**Примеры правильных имён:** `chateau-bagnols-2024.jpg`, `cannes-gala.jpg`  
**Примеры неправильных:** `Свадьба Château.jpg`, `фото 1.jpg`
